# React Product Catalog

A React application displaying a responsive grid catalog of retail products.

## Key Features
- **Dynamic Catalog Render**: Generates a catalog list of clothing, jewelry, and electronic products from a data list.
- **Component Reusability**: Employs nested `<Product />` cards to represent details including ratings, descriptions, prices, and preview images.
- **Responsive Grid Layout**: Structured with CSS grids to adapt to phone, tablet, and desktop viewports.

## Commands
- **Start Local Server**: `npm run dev`
- **Build Production Assets**: `npm run build`
