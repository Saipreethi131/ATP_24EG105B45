# Web Layouts & React Basics - Week 5

This folder contains intermediate web development projects, covering pure CSS layouts, utility styling with Tailwind CSS, and component-based applications in React.

---
## 📂 Project Folders

### ⚛️ React Apps
* **`React_Product_Catalog`**: A React application displaying a responsive grid of products mapped from catalog data.
* **`React_User_Directory`**: A React app organized into clean, reusable components (`Navbar`, `UserList`, `User`, `Footer`) to show team members.
* **`React_Project_Portfolio`**: A developer project portfolio showcasing recent development projects.

### 🌀 Tailwind CSS
* **`Tailwind_Page`**: An informational landing page built completely with utility-first Tailwind CSS.

---

## 📄 Web Pages (HTML & CSS)

* **`flex_layout.html` & `flex_layout.css`**
  A standard marketing landing template demonstrating CSS Flexbox cards and column grids.

* **`Tourist_Places.html` & `Tourist_Places.css`**
  A grid layout showcasing key travel attractions in Hyderabad (Charminar, Golconda Fort, etc.).

* **`user_table.html` & `user_table.css`**
  A styled tabular interface displaying user profile cards, email addresses, and roles.

* **`complex_tables.html` & `complex_tables.css`**
  Demonstrates complex HTML structures using row merges (`rowspan`) and column merges (`colspan`) for data tables.
