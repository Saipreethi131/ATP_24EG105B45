# React Project Portfolio

A modern developer portfolio landing page built to showcase projects.

## Key Features
- **Developer Project Showcase**: Renders interactive cards representing recent developer builds (e.g., News feeds, blogging apps, statistical trackers).
- **Clean Section Division**: Uses a modular `<Profiles />` section feeding structured project parameters down into individual `<Profile />` components.
- **Modern UI Styling**: Incorporates neat card structures with author labels and live preview images.

## Commands
- **Start Local Server**: `npm run dev`
- **Build Production Assets**: `npm run build`
