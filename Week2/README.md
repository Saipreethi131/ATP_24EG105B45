# JavaScript & Backend Development - Week 2

This folder contains intermediate JavaScript exercises, modular coding assignments, and a sample Node.js backend project.

---
## 📂 Projects

* **`E_Commerce`**: A modular e-commerce shopping cart system with separate modules for products, cart, payments, discounts, and main app logic.
* **`Task_Management`**: A modular app to manage, search, and validate daily user tasks.
* **`Sample_Backend`**: A sample Express.js backend server with API routing.

---

## 📄 Standalone Programs

* **`shoppingCart.js`**: Functions to add, remove, and calculate total price for items in a cart.
* **`temperatureAnalyser.js`**: Analyzes a week's temperature data to find averages, highs, and lows.
* **`onlineCourse.js`**: Tracks user enrollment and progress through online training courses.
* **`studentPerformance.js`**: Analyzes student test results and grades them accordingly.
* **`employeePayroll.js`**: Computes salary details, tax deductions, and net pay for employees.
* **`studentMarks.js`**: Simple tracker to calculate average marks and student passing status.
* **`movieStreaming.js`**: Recommends movies and tracks viewed history for users.
* **`bankTransaction.js`**: Handles deposits, withdrawals, and balance verification.

### 📚 Advanced ES6+ & Copying Concepts
* **`libraryBook.js`**: A book reservation tracker for a library.
* **`arrayCopy.js` & `objectCopy.js`**: Simple examples showing how to clone lists and objects.
* **`shallowCopy.js` & `deepCopy.js`**: Practical examples showing the difference between shallow cloning (copying references) and deep cloning (copying nested values).
* **`restParameter.js`**: Demonstrates the use of the rest parameter (`...args`) to accept a flexible number of arguments in a function.

### ⏱️ Asynchronous Timers
* **`setTimeout.js`**: Runs a specific task once after a scheduled delay.
* **`setInterval.js`**: Repeats a specific task periodically at a regular time interval.
