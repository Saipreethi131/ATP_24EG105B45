# JavaScript Basics - Week 1

Here is a simple summary of the basic JavaScript features used in this week's programs:

### 1. Storing Data (Variables)
* **`let`**: Used for values that will change (like sums or counters).
* **`const`**: Used for values or lists that stay the same.

### 2. Making Decisions (Conditionals)
* **`if / else`**: Runs code only when a condition is met.
* **Ternary (`? :`)**: A quick, one-line way to choose between two options.
  * *Example:* `let big = (a > b) ? a : b;`

### 3. Comparing Things (Operators)
* **`>` / `<` / `>=`**: To compare numbers.
* **`&&` (AND)**: Used when two or more conditions must both be true.
* **`===`**: Checks if two values are exactly the same.

### 4. Working with Lists (Arrays)
* **Arrays `[]`**: Used to store a list of items (like a list of numbers or names).
* **`marks[0]`**: Gets the very first item in a list (starts counting from 0).

### 5. Repeating Tasks (Loops)
* **`for...of`**: A simple way to go through each item in a list one by one.
* **Standard `for`**: Used when we need to track the position (index) of items.

### 6. Grouping Details (Objects)
* **Objects `{}`**: Used to group related details together in key-value pairs.
  * *Example:* `{ eno: 101, name: "Ravi" }`

### 7. Changing Lists (`splice`)
* **`splice()`**: A tool to edit lists. It is used to **add**, **remove**, or **replace** items inside an array.

### 8. Reusable Code (Functions)
* **Functions**: Blocks of code we can write once and run multiple times with different values.
* **Arrow Functions `=>`**: A modern, shorter way to write functions.
