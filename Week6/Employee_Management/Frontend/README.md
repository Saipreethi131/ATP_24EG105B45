# Employee Management - Frontend

A React Single Page Application (SPA) built with Vite and Tailwind CSS.

## Development Commands
- **Start Local Server**: `npm run dev`
- **Build Production Assets**: `npm run build`

## Environment Variables
- `VITE_API_URL`: Configures the base URL for the deployed backend service (e.g., `https://api.onrender.com`). Falls back to `http://localhost:3000` automatically during local development.
