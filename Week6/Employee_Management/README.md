# Employee Management Portal

A full-stack MERN application to create, view, edit, and delete employee profiles.

## Project Structure
- **`Frontend/`**: React SPA (Vite + Tailwind CSS)
- **`Backend/`**: Express.js REST API + MongoDB (Mongoose)

## Getting Started

### 1. Start the Backend
1. Navigate to the folder: `cd Backend`
2. Install dependencies: `npm install`
3. Configure your database URI inside a `.env` file (`DB_URL` and `PORT`).
4. Start the server: `npm start`

### 2. Start the Frontend
1. Navigate to the folder: `cd Frontend`
2. Install dependencies: `npm install`
3. Start the development client: `npm run dev`
