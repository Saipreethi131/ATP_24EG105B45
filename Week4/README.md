# HTML & CSS Basics - Week 4

This folder contains introductory assignments for web design covering HTML5 markup and basic CSS layout concepts.

---
## 📄 Web Pages

* **`html_basics.html`**
  An introduction to standard HTML document structure. It includes headers, paragraphs, a link to Google, and an unordered list of tech companies.

* **`nested_lists.html`**
  Demonstrates how to write nested HTML lists inside one another to create organized hierarchical categories (Fruits, Vegetables, Cereals, and Nuts).

* **`cat_profile.html`**
  An adoption profile page for a cat named "Pochi". It uses structured paragraphs, lists for hobbies, external links, an image layout, and custom style rules.

---

## 🎨 Stylesheets

* **`cat_profile.css`**
  Styles the cat profile page by floating the profile image to the right and applying a custom `bisque` background color to the webpage body.
